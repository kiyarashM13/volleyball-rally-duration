# Rally duration

Recorded rally duration for the Volleyball Nations League final eights in 2025 and 2026 and the 2026 European Championship final eight. Women and men are reported separately.

Duration is the last skill `video_time` minus the serve `video_time`. The page is published with GitHub Pages.

The same page has four tabs: an overview with 2025 and 2026 side by side, the duration and action counts, each match, and a short account of how the figures were calculated. [By tournament](sets.html) opens one competition at a time, then a match, then each set, with duration and the skill counts.
